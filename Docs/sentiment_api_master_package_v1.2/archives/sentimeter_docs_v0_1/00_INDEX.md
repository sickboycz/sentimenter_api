# Sentimeter Brain – Documentation Package (v0.1)
Date: 2026-02-01

Standalone news+market intelligence system (“Sentimeter”):
- crawls live + historical news (archive backfill)
- builds multi-resolution memory (L0–L4) + vector memory
- ingests SPY price history for correlation + impact calibration
- outputs impact-scored sentiment + event stream
- exposes a rich API
