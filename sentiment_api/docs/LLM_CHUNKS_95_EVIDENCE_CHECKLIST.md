# Evidence Checklist (v1.0)

For each L2+ ticker allocation:
- evidence_ids must be non-empty OR rationale must state why evidence missing
- symbol must exist in universe
- rationale_en must be present

For each market/sector allocation:
- rationale_en present
- confidence present

Debug endpoint must show:
- packet
- channels + why_refs
- sector allocation list
- ticker winners/losers
